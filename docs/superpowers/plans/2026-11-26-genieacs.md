# Integrasi GenieACS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin dan teknisi bisa melihat status/redaman ONT pelanggan, me-reboot ONT, melihat dan mengganti WiFi 2,4/5 GHz, serta menghubungkan ONT yang belum terhubung, langsung dari aplikasi billing lewat NBI GenieACS.

**Architecture:** Satu service tipis `GenieAcsService` di atas `Illuminate\Support\Facades\Http` yang bicara ke NBI GenieACS secara langsung (tanpa salinan lokal). `OntController` memakai service itu untuk halaman ONT per pelanggan dan halaman ONT belum terhubung. Perbedaan antar-merek ONT ditangani di GenieACS oleh virtual parameter (skrip JS di `docs/genieacs/`), jadi aplikasi selalu membaca nama yang sama.

**Tech Stack:** Laravel 13, PHP 8.5, Blade + Materialize (Bootstrap 5), jQuery/toastr, PHPUnit 12 (`#[DataProvider]` attribute, bukan docblock), MariaDB test DB `lamtim_biling_test`.

**Spec:** `docs/superpowers/specs/2026-11-26-genieacs-design.md`

## Global Constraints

- Konfigurasi lewat `.env`: `GENIEACS_URL` (kosong = fitur ONT mati total), `GENIEACS_USER`, `GENIEACS_PASS` (opsional, Basic Auth), `GENIEACS_ONLINE_MENIT` (default 10 = 2 × interval inform 5 menit).
- Timeout HTTP ke NBI: 5 detik. Task memakai `?timeout=3000&connection_request`.
- Hak akses semua fitur ONT: role 1, 2, 4, 7. Role 3 dan 6 ditolak (403).
- Virtual parameter yang **sudah ada** di GenieACS pemilik dan dipakai apa adanya (jangan diubah): `VirtualParameters.pppoeUsername`, `RXPower` (string dBm atau `"N/A"`), `getSerialNumber` (SN teks seperti label ONT), `WlanPassword` (cadangan password bila per-pita kosong). Yang **baru** (Task 6): `wifiSsid`, `wifiPassword`, `wifiSsid5`, `wifiPassword5`.
- Validasi WiFi: SSID 1–32 karakter; password 8–63 karakter; kolom kosong = tidak diubah.
- Ambang redaman: ≥ -25 dBm "baik" (hijau), -25 sampai -27 "waspada" (kuning), < -27 "buruk" (merah).
- NBI 200 = selesai; 202 = antri (ONT tidak merespons); gagal koneksi/5xx = "GenieACS tidak terjangkau". Jangan pernah tampilkan 202 sebagai berhasil.
- Log setiap reboot, ganti WiFi, dan hubungkan: user, pelanggan, SN, hasil. Password WiFi **tidak** dicatat.
- Satu SN hanya untuk satu pelanggan (`lamtim_user_mikrotik_details.ont_sn`).
- Teks UI berbahasa Indonesia; tanggal lewat `Carbon::locale('id')`.

## Review Focus

1. **GenieACS mati atau lambat**: halaman ONT tetap terbuka (HTTP 200) dengan pesan "GenieACS tidak terjangkau", bukan error 500. Diuji di Task 3.
2. **ONT offline saat ganti WiFi (NBI 202)**: pesan kuning "akan dijalankan saat ONT online", `wifi_name` tidak berubah. Diuji di Task 3.
3. **Input WiFi aneh**: SSID 33 karakter, password 7 karakter, atau semua kolom kosong ditolak 422; SSID berspasi diterima apa adanya. Diuji di Task 3.
4. **Pelanggan tanpa username PPPoE dan tanpa SN**: tidak mengirim query ke NBI dengan nilai null; langsung "belum terhubung". Diuji di Task 1.
5. **Username PPPoE cocok ke lebih dari satu ONT**: tidak menghubungkan otomatis; kembalikan daftar kandidat. Diuji di Task 1.
